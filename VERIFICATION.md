# Проверка версии

Проверено 30 сентября 2026 года.

## Автоматические проверки Python

15 из 15 тестов `python -m unittest -v test_app` прошли.

- Создание от обеих ролей, вход по ID, оплата, подтверждение, возврат.
- Запрет оплаты продавцом и подтверждения получения продавцом.
- Запрет чужого просмотра после присоединения участника.
- Недостаток средств и запрет отрицательных, нечисловых или неточных сумм.
- Повторные и конкурентные списания/выплаты: единственное изменение баланса.
- Сохранение сделок и реквизитов при повторном открытии базы.
- Проверка Telegram HMAC, отклонение подмены, дублей полей, устаревшего и будущего времени.
- Отсутствие автоматического обхода входа Telegram без токена.
- Запрет тестового пополнения и оплаты при отключённом режиме платежей.
- Проверка ролей администратора, JSON и источника запроса.
- Отзывы только после завершения, только участникам и без повторов.
- Отказ в сохранении полного номера банковской карты.
- Корректная выдача HTML и статических ресурсов; приватные Python-файлы не выдаются как статика.

## Интеграция интерфейса

Пройден автоматизированный сценарий в DOM-среде с двумя отдельными окнами и настоящим Flask API/SQLite через тестовый HTTP-клиент:

1. Создание сделки и превью NFT-ссылки.
2. Копирование ссылки и открытие другим участником.
3. Присоединение, тестовое пополнение, тестовая оплата.
4. Автоматическое обновление статуса в окне продавца.
5. Подтверждение покупателем, баланс продавца и обновление завершённой сделки.
6. Сохранение реквизитов и восстановление данных после повторного открытия интерфейса.
7. Профиль, отдельный браузерный демонстрационный режим.
8. Открытие исходного `index.html` из вложенной папки, как при локальном просмотре: CSS, JavaScript и логотип разрешаются относительно файла, а исходная настройка запускает демонстрацию.
9. Лента подарков заполнена до создания сделок и не обозначает подарки как совершённые продажи. Анимации выдаются как JSON из локальных файлов проекта.

Проверен синтаксис JavaScript через `node --check`, Python — через компиляцию модулей.

Это не визуальная проверка в реальном браузере или реальном Telegram. Скриншотная проверка мобильной верстки, загрузка внешних Lottie-анимаций и WebMCP в поддерживаемом браузере в этой среде не выполнены. Реальные платежи, BotFather, публичный HTTPS-сервер и реальный токен бота не проверялись, поскольку они не подключены.
