# Проверка версии

Проверено 30 сентября 2026 года.

- `python -m unittest -q test_app`: 24 теста успешно. В частности, проверены уникальность и ввод шестизначных кодов, ограничение попыток, перенос существующей базы на коды, сделка и баланс, сохранение только отзывов из ворк-панели.
- `node --check static/script.js`: синтаксис JavaScript корректен.
- `python -m py_compile main.py database.py bot.py`: синтаксис Python корректен.

Обычные отзывы хранятся только в памяти страницы браузера; автоматические тесты проверяют, что API не сохраняет их в SQLite. Поведение обновления страницы в реальном Telegram Mini App в этой проверке не воспроизводилось. Реальные платежи и Telegram webhook с рабочим токеном также не проверялись: платёжный провайдер не подключён.
